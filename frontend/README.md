### 🛠️ Architecture Overview
This frontend uses **Next.js 14** with the **App Router**, **Tailwind CSS**, and **Framer Motion** for premium visuals.

- **`/user`**: Citizen dashboard (Complaints & Predictions).
- **`/admin`**: Officer dashboard (Resolve Ward complaints).
- **`/superadmin`**: Governance oversight (Nagar Sevak Management).

### 🚀 To Run:
1. Ensure the Python AI backend (`http://127.0.0.1:5000`) is running.
2. `npm install`
3. `npm run dev`
4. Access `http://localhost:3000`
